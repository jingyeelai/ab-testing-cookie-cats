# Data

The dataset is not stored in this repository.

1. Download `cookie_cats.csv` from Kaggle: https://www.kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats
2. Save it in this folder as `data/cookie_cats.csv`.

| Column | Description |
|---|---|
| `userid` | Unique player id |
| `version` | `gate_30` (control) or `gate_40` (treatment) |
| `sum_gamerounds` | Game rounds played in the first 14 days after install |
| `retention_1` | Did the player come back 1 day after install? |
| `retention_7` | Did the player come back 7 days after install? |
